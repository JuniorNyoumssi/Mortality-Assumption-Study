# Mortality-Assumption-Study
This project develops a preliminary mortality assumption-setting workflow for a synthetic life insurance portfolio.



This project develops a preliminary mortality assumption-setting workflow for a synthetic life insurance portfolio. The workflow combines data preparation, Poisson generalized linear modelling (GLM), model comparison, in-sample calibration and ranking diagnostics, age-band credibility blending, a 2025 reference-year basis, and a preliminary select-and-ultimate structure.

The objective is to demonstrate how an actuary can turn policy-level experience into a documented mortality assumption basis. The work covers:

•	Preparing policy-year exposure and mortality data for modelling.

•	Fitting a mortality GLM with an exposure offset and nonlinear age/duration terms.

•	Comparing candidate model specifications and reviewing in-sample calibration and ranking.

•	Blending age-band experience with model-based expected mortality using a credibility factor.

•	Standardizing predictions to a common reference year and producing illustrative 2026 rates.

•	Constructing a preliminary duration-based select-and-ultimate view and documenting its limitations.
Out of scope for this iteration: a fully validated single-age select-and-ultimate table, independent holdout validation, formal mortality-improvement research, assumption approval, and integration into a production pricing or valuation system.
